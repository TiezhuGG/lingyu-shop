# 本地开发图片私有暂存适配

当前仅提供 server-modules 的 LocalImageStore 基础适配，无 HTTP 上传/下载端点、无资产表/归属/票据/扫描/READY 决策、无 CMS 发布或界面。未装配为 API/Worker 自动启动服务，不创建默认存储目录，不改变启动方式。

只允许 development/test，进程 NODE_ENV=production 时即便调用者误传 development 也拒绝。目录为服务端绝对路径；拒绝解析后的盘根、目录及祖先软链接/junction。Windows 仅允许本地盘绝对路径，不接 UNC/设备路径；允许短路径与大小写差异后使用 canonical 路径。Linux 继续检查目录属主及私有权限，创建文件 0600。

Windows 在新建暂存目录且尚无图片字节时设置保护 DACL，只允许进程用户和 SYSTEM；已有目录只验证不修改。目录继承未关闭或目录/文件存在其他 SID 的 allow ACE 则拒绝；属主只接受当前用户、SYSTEM 或本地 Administrators（Windows 提升权限创建文件的属主可能为管理员组）。此适配使用系统 Windows PowerShell/.NET ACL API；不可用、超时或权限验证失败时返回固定错误，不降级跳过 ACL。只处理暂存目录，不修改父目录或系统安全设置。开发 Windows 验证不证明生产存储已验收。

仅暂存声明为 PNG/JPEG 且基本签名相符、大小 1～2097152 字节的数据。基本签名不是完整解码、内容清洗或恶意文件扫描；结果始终 developmentOnly=true、scanStatus=UNVERIFIED，不可作为可公开资产凭证。

key 由 SHA-256 与受控后缀生成，不接收原始文件名/任意路径。先在私有目录独占写临时文件并同步，再以不覆盖目标的硬链接原子发布；完成后移除自身临时文件。同内容重复保存校验摘要；读取先 lstat 拒绝文件链接，打开后用 bigint dev/ino 比较路径和句柄身份，再读取与检查大小/摘要。平台有 O_NOFOLLOW 时同时使用该标志，Windows 未提供该标志时仍执行身份与 ACL 检查。异常只返回固定错误，不泄露系统路径/内容。已有文件损坏不会自动覆盖修复。

进程崩溃可能留下私有 .upload-* 文件；没有目录公开服务，用户路径不能访问它们。未来 Asset 接入需补元数据/配额/生命周期、孤儿清理与实际扫描，不能把暂存成功当 T04-A 或 T03-C 完成。不同文件系统的硬链接支持/故障恢复未验收，失败关闭而非覆盖目标文件。
