# 固定故事与协议纯文本 CMS

## 范围与页面

支持单 ONLINE 销售范围的 STORY/TERMS/PRIVACY（品牌故事、服务条款、隐私说明），不接受 MARKET 或任意页码。迁移、读取均不 seed 商城、账号或文案。保存需先配置商城名称，但不要求真实门店。无正式文案时公开为空，功能不代表正式经营文案审核、同意记录或法律效力。

标题最多80个 Unicode 字符，正文最多12000，保存去首尾空白；空草稿可保存，但空白标题/正文不能发布。标题拒绝控制字符，正文仅允许换行/回车/制表符等正常文本格式，不接受 NUL 等危险控制字符。两端插值展示纯文本，不用 v-html/rich-text，不解析 HTML/Markdown/脚本/外链。图片/Banner/促销专区/更多菜单、资产上传/扫描留 T03-C2/T04-A。

## API 与权限

OpenAPI 为单一 DTO 来源，未知字段拒绝。后台 GET/PUT `/api/v1/admin/cms/{pageCode}`，POST `/{pageCode}/publish`、`/rollback`、`/withdraw`；公开 GET `/api/v1/app/cms/{pageCode}`。上述 POST 均相对 `/api/v1/admin/cms`。不接受客户端 actor/store_id/blocks 或任意路由。所有响应 no-store，错误不回显正文、凭据或系统信息。

cms.read/write/publish 按同一商城范围分别授权，STORE_OPERATOR 可操作，STORE_READER 只读；GLOBAL IAM 或其他范围不代替业务权限。Cookie、Origin、CSRF 和事务内实时会话/撤权校验沿用 IAM。

公开仅返回 pageCode 与 published 快照或 null，不返回草稿/历史。后台返回当前草稿、聚合版本、当前 published、历史快照及分页。历史按版本降序每页10条，before 为可选正整数十进制字符串（不超过2147483647），响应 hasMore/nextCursor；客户端加载更早记录时若聚合已更新，提示重载而不覆盖输入。

## 发布、回退与事务

CMS 拥有 cms_text_page/cms_text_revision，关联 Store 只通过公共读取接口。首次保存 expected version=0，之后保存/发布/回退/撤下均递增聚合版本；同版本重放/并发至多一笔生效，其余409。不可发布空文案。

发布追加不可覆盖的标题/正文/时间快照并原子切换公开指针；编辑草稿不污染公开内容。回退使用本页存在的 targetVersion，将历史内容复制为新发布版本，记录 sourceVersion，不改变当前草稿，不覆盖或倒退历史。撤下清空公开指针，保留草稿/历史，可以再发布或回退。

写事务顺序 IAM 事务锁→管理员/会话行→CMS 聚合；Serializable 整笔有限重试，首建唯一冲突转409。聚合/快照/指针与成功审计同事务，审计失败全部回滚；受控拒绝另记脱敏审计。审计只存范围/页码、前后版本、来源版本、正文长度与受控原因，不存正文或凭据。无事务内外部存储/网络副作用。

## 界面与恢复

后台支持固定页面选择并明确重载、纯文本编辑/预览、公开内容查看、分页历史、指定历史预览回退、发布/撤下确认。显示当前公开标题/版本与目标正文；未保存修改时禁用发布/回退/撤下，冲突不自动覆盖。未配置商城、无权、只读、空/失败状态明确。

“我的”提供三个固定阅读入口至 `pages/content/index?pageCode=STORY|TERMS|PRIVACY`。阅读页只允许已编译枚举，非法参数不请求接口；公开为空、失败重试、刷新/重返重读有独立状态，不拿样例文案填空。页面不记录/暗示用户已同意。H5 同源，原生目标需显式 VITE_API_BASE_URL，生产自定义地址仅HTTPS且拒绝凭据/查询参数；不证明微信真机/合法域名验收。

第七迁移追加两表，无默认文案。FK/唯一/CHECK 约束页码、长度、正版本、当前公开指针及同页回退来源；正文语义/控制字符由 DTO 约束。空 schema 全量迁移与旧库前向升级验收；回退旧应用保留数据，前向修复，不 drop/reset/删除历史。生产部署、正式文案及用户同意流程另行验收。
