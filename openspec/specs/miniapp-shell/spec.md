# 小程序一期界面外壳

## 当前能力
- 主包包含 `pages/index/index`（发现）、`pages/market/index`（市集）、`pages/mine/index`（我的），通过原生 tabBar 切换。
- 发现页展示标记的示例图文，支持话题筛选；关注无示例关系时显示空态。
- 市集展示标记的示例分类/商品/价格，支持分类和自提/配送模式预览；不提供搜索、加购或结算服务。
- 我的展示游客占位，不展示虚构资产、会员等级或订单；登录、订单和服务入口禁用并注明尚未开放。
- 通用组件支持加载、空白、错误与重试预览；开发模式可切换状态，生产模式不显示状态控制。
- 三页始终显示界面预览提示；示例价格以整数分表示，展示格式化不承担报价或结算职责。

## 验收场景
1. 点击话题/分类，选中样式与示例列表同步；没有内容时显示空态。
2. 开发模式切换加载/空白/错误，显示对应组件；错误重试恢复示例状态。
3. 滚动发现页，切换市集再返回，保持话题及滚动位置（H5 已验证；微信真机待 T13）。
4. 320/375 宽度下列表独立滚动，购物车占位与 tabBar 可见，页面无横向溢出。
5. 点击禁用业务入口不产生登录、资产、购物车或订单事实。

## 能力边界
这不是 P1-A 总验收或真实业务完成；API、持久化、微信登录/真机、交易及服务分别由后续任务交付。原生 tabBar 负责底部安全区；页面内容底部也使用安全区 CSS。真机与弱网验证没有被 H5 替代。
