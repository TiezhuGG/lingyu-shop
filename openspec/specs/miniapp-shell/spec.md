# 小程序一期界面外壳

## 当前能力
- 主包包含 `pages/index/index`（发现）、`pages/market/index`（市集）、`pages/mine/index`（我的），通过原生 tabBar 切换。
- 发现页展示标记的示例图文，支持话题筛选；关注无示例关系时显示空态。
- 市集商城名称由 T03-A0 服务读取，商品改由 T03-B 已发布目录读取，支持真实空态、错误重试与后续页；不再以示例商品/价格替代。按用户商城先行选择，不展示虚构门店或自提/配送预览切换；明确保留快递/同城/自提且当前未开通。不提供分类筛选、搜索、规格选择、库存、加购或结算服务。
- 我的展示游客占位，不展示虚构资产、会员等级或订单；登录/订单及尚未交付的服务入口禁用。品牌故事/服务条款/隐私说明连接 T03-C1 的真实公开阅读页，无内容为空、失败可重试，不记录用户同意。
- 发现/我的仍使用通用加载、空白、错误与重试预览；开发模式可切换状态，生产模式不显示状态控制。市集展示真实服务状态，不保留演示状态切换。
- 发现/我的显示界面预览提示；市集说明商品来自已发布目录但库存/购物车/交易未开放。价格以整数分传输并纯字符串格式化，不承担报价或结算职责。

## 验收场景
1. 点击发现话题，选中样式与示例列表同步；没有内容时显示空态。市集分类筛选留 T05-B，当前只显示全部已发布商品。
2. 发现/我的开发模式切换加载/空白/错误，显示对应组件；市集错误重试真实请求，不恢复示例价格。
3. 滚动发现页，切换市集再返回，保持话题及滚动位置（H5 已验证；微信真机待 T13）。
4. 320/375 宽度下列表独立滚动，购物车占位与 tabBar 可见，页面无横向溢出。
5. 点击禁用业务入口不产生登录、资产、购物车或订单事实。

## 能力边界
这不是 P1-A 总验收或真实业务全部完成；商城/目录 API 与持久化见对应规格，微信登录/真机、购物车、交易及服务仍分别验收。原生 tabBar 负责底部安全区；页面内容底部也使用安全区 CSS。真机与弱网验证没有被 H5 替代。
