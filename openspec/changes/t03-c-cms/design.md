# T03-C 固定 CMS 与本地开发图片依赖

状态：实施设计，不代表当前 CMS 功能。用户选择本机开发存储、生产关闭。保留 ADR-003 纯商城和三种履约尚未开通的边界。

## 分批边界

- C0：本地开发图片暂存适配与保护测试。本批只交付基础适配；不接 HTTP、不建立 READY 资产、不提供公开文件服务，不代表完整 T04-A 上传/扫描。
- C1：固定 CMS 的纯文本故事/协议、草稿、不可覆盖发布版本、回退为新发布版本、后台和用户端固定路由。没有真实文案时为空，不代写可生效的经营协议或品牌故事。
- C2：上传票据/确认/归属与状态（T04-A 的资产子依赖）、Banner 图片、固定促销商品专区、更多菜单，连接 CMS 发布。先在开发环境验证，真实扫描/云存储分别验收；生产缺服务时拒绝发布图片。

## C0 保护规则

适配器仅接受 development/test；其他环境在任何文件访问前拒绝。暂存目录由服务端提供绝对路径，拒绝根目录、软链接、组/其他用户可访问的目录。文件名来自内容 SHA-256 和受控后缀，不接收用户路径或原始文件名；只暂存 PNG/JPEG，限制 2 MiB，并核对签名与声明类型。格式签名检查不是完整图片解码或恶意内容扫描。

同内容写入使用独占创建，重复写入校验摘要，不覆盖既有内容；读取只允许受控 key、限制长度并复核摘要。返回 scanStatus=UNVERIFIED 和 developmentOnly=true，绝不能凭暂存成功启用公开或 CMS 发布。仅后续 Asset 模块能在完成归属、实际解码/安全验证和状态事务后作 READY 决策。失败使用固定错误，不回显路径、文件或系统异常。

## 后续 CMS 事务与接口设计

CMS 拥有 layout 草稿、layout_version 与当前发布指针，固定页码 MARKET/STORY/TERMS/PRIVACY，不接任意页码/组件类型。拟定后台 /api/v1/admin/cms/{pageCode} GET/PUT、publish、rollback，公开 /api/v1/app/cms/{pageCode} GET；实施时统一加入 OpenAPI，不在当前契约提前宣布未实现接口。

增加 cms.read/write/publish，同销售范围分别鉴权；STORE_OPERATOR 获业务权限，STORE_READER 只读，GLOBAL IAM 不代替业务角色。Cookie/Origin/CSRF 与事务内实时撤权复用 IAM。version 控制保存/发布/回退，过期返回 409。成功与审计同一 Serializable 事务，失败全部回滚；锁顺序 IAM→CMS 聚合→按 ID 有序读取 Asset/Catalog 公共接口，事务内不访问外部存储。

固定 Banner 只接 Asset ID 与固定路由枚举，不接任意 HTML、JS、URL、导航路径或客户端价格。促销专区只保存商品 ID 与文字，不创造折扣；读取时经 Catalog 公共接口重新取得当前发布商品与价目，已下架商品不保留可购买入口。未知类型/目标安全拒绝，异常时保留基础商品列表。

回退必须验证目标历史版本存在、图片仍可公开及路由白名单，复制为新发布版本；旧版本不可覆盖，不倒退聚合版本。新迁移只追加、无默认生效文案。回退应用保留历史和图片元数据，前向修复；不自动删库、删历史或删文件来恢复。

## 验收

C0：环境门禁、目录/路径/软链接拒绝、类型/签名/大小限制、原子重复写入、读取篡改拒绝与 UNVERIFIED 状态；只用临时目录测试并精确清理。

C1/C2：草稿不公开、版本/回退不可覆盖、跨范围/只读/撤权/CSRF、并发 409、审计失败回滚、错误资产归属/未 READY 拒绝、历史引用撤销后 fail closed、商品下架过滤、XSS/任意外链/路由绕过、空库与升级迁移、重启恢复、后台及 H5 流程。展示、开发替代与生产扫描/微信真机分开。
