以归档 5000.html 为结构参考，实现发现、市集、我的三个主包页面和原生 tabBar。页面使用独立 scroll-view；原生 tab 页面保留导航与滚动状态，后续详情通过普通路由进入，不模拟单页导航。

本批仅交付界面预览。图文与商品集中在 preview-fixtures.ts，不接 API，不写购物车、用户资产或交易状态。未实现的业务按钮禁用并说明尚未开放。资产显示“— / 待接入”，余额显示“未开通”，不伪造会员、定位、优惠券、销量或订单。

ui-tokens 提供 CSS 变量；PreviewNotice、PageState、PreviewStates、ContentCard、ProductCard 是纯视觉组件。页面仅维护话题、分类、配送模式。开发环境可切换 ready/loading/empty/error，重试只恢复示例内容；生产构建不显示状态控制，始终保留示例标记。
