# ADR-003：先纯商城，实体仓店按需启用

状态：采纳。日期：2026-10-19。

用户选择暂不使用真实门店，保留门店方向，先做商城。因此一期商品浏览/管理不以真实门店地址、营业时间、定位和服务区为前置。该选择不是“仅演示版”或免除真实交易/微信验收。

保留 store_id 作为单销售范围、商品/价格/购物车及授权的归属键；ONLINE 范围不宣称真实仓库或门店。用户补充快递、同城、自提规则仍需保留，因此 T03-A0 同时交付商城基础和三种规则草稿配置，T03-B 依赖 A0；实际仓店/营业/可执行服务区校验与开通拆入 T03-A1。公开展示和后台必须区分草稿、已开通履约和真实门店，不预置假地址、营业政策、距离、收费或配送承诺。

当前未实现的实体门店、配送、交易能力默认关闭；不可通过修改普通商城设置越过门槛。快递、同城、自提及运费政策在真实结算/履约任务前另行确认，不从“纯商城”推断配送方式。

代价：商品浏览可先行，但真正下单/履约仍需后续规则；未来实际仓店与单销售范围的映射须显式迁移，不把 ONLINE 记录伪装成既有实体。恢复为实体仓店路线时保留已有关联 ID 与用户数据，先补规格与验证，再开通能力。
