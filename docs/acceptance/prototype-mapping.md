## 验收记录模板与门槛

每个表项允许按操作继续拆用例，实际验收记录放到对应任务批次：`ID / 规格 / 实际路由与后台 / API / 测试ID / 环境 / 证据路径 / 状态 / 未完成说明`。截图只证明界面，服务端结果、权限、重启恢复与并发用例需要相应自动化或实际操作记录。

- P1-A：P1-01～12 的界面与已规划补齐流程可用，真实交易项尚未接入时标明演示和未完成；完成不等于 P1-B 完成。
- P1-B：真实交易、权益、库存、履约、售后、对账以及真机/恢复门槛全部通过；默认完成后进入第二原型实现。
- P2：全部子项覆盖；直播/卡/活动规则未定即对应项阻塞，不能用 toast 或隐藏入口结项。第一阶段能力回归通过。
