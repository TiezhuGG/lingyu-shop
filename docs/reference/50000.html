页面跳转

建议按这个顺序体验

  1. 首页点任一商品卡 → 进商品详情
  2. 点加入购物车 → 看底部角标 +1 并弹提示
  3. 切到底部 购物车 → 调数量、勾选，看免运费进度条与金额实时变化
  4. 点去结算 → 确认订单页改配送时段、开关朴分
  5. 点提交订单 → 支付中动画 → 支付成功 → 订单追踪时间轴
  6. 首页 金刚区 20 格（前两行 10 格固定 / 后 10 格横滑）点任一品类 → 直达分类页对应类目
  7. 首页一直向上滑动：先是搜索框吸顶（第 1 层，滚出头图才滑下来）；继续滑到推荐流头部的「为你推荐」Tab 行时，它才吸住（第 2 层，贴在搜索框下方）——不是一滚动 Tab 就吸顶；再往下是瀑布流（同一页，非二级页）
  8. 底部 我的 → 进订单列表，点订单卡回到追踪页
  9. 底部 分类 Tab → 切左侧一级类目，右侧商品联动
